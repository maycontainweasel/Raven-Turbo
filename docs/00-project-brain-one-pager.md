# Project Brain One-Pager

Project Brain is a portable Markdown memory system for AI-assisted projects.

It preserves the raw journey of a project while maintaining concise current files that help a future human or AI understand what this is, why it matters, what was decided, and what is still unresolved.

Short form:

> Nothing lost. Nothing drowning. Always ready to continue.

## What It Captures

- raw prompts, responses, notes, and external reviews
- distilled project understanding
- identity signals and durable tenets
- decisions, open loops, questions, ideas, risks, and opportunities
- current status and handoff context

## How It Works

- **Raw memory:** verbatim source material.
- **Distilled memory:** extracted meaning, decisions, themes, risks, and identity.
- **Active memory:** concise files such as `NOW.md`, `HANDOFF.md`, and `EXECUTIVE_SUMMARY.md`.

## Operating Modes

- `Brain Ingest Pair`
- `Brain Backfill`
- `Brain External Review`
- `Brain Assist Mode`
- `Brain Checkpoint`
- `Brain Deploy`
- `Brain Health`

## Orbit Relationship

This Brain can run without Orbit. If Orbit is connected, Orbit is planning/control and this Markdown Brain is portable narrative memory.
