# Brainkeeper Ingest

## Read First

1. `AGENTS.md`
2. `brain/START_HERE.md`
3. `brain/NOW.md`
4. `brain/HANDOFF.md`
5. `brain/INGEST.md`
6. `brain/CAPTURE_QUEUE.md`
7. `brain/BRAIN_CHARTER.md`
8. `brain/AGENT_PROTOCOL.md`

## Workflow

1. Determine mode: `backfill`, `external-validation`, `live-capture`, or `pre-work-primer`.
2. Save raw source verbatim using `brain/INGEST.md`.
3. Create the appropriate record and distillation.
4. Extract identity signals, tenets, vision deltas, decisions, open loops, questions, risks, opportunities, repeated themes, and Orbit sync candidates.
5. Update indexes and active Brain files only where warranted.
6. Produce a Brain Patch.

## Rules

- Do not implement code while acting as Brainkeeper.
- Preserve uncertainty.
- Do not overwrite raw source.
- Do not invent decisions.
- Use `brain/CAPTURE_QUEUE.md` for durable signals that should wait for a checkpoint.
