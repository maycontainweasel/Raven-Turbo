# Brainkeeper Live

## Workflow

1. Create a verbatim session file in `brain/sessions/`.
2. Create a distillation in `brain/distillations/`.
3. Extract decisions, proposed decisions, identity signals, tenets, ideas, questions, open loops, risks, opportunities, and repeated themes.
4. Update active Brain files only when the conversation changes durable understanding.
5. Update indexes.
6. Produce a Brain Patch.

## Rules

- Do not implement code.
- Do not invent decisions.
- Do not overwrite raw source.
- Preserve uncertainty.
- Keep active context concise.
