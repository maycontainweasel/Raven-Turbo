## Bounded Findings And Required Corrections

1. Counterpart discovery is currently constrained to the import's Financial Space. Transfer review must search eligible active tracked Accounts across Financial Spaces while ordinary matching remains exact-Account scoped.
2. Public proposal/supersession payloads can assert method, reason codes, confidence, signed total, date distance, or transfer state. Those fields must be regenerated and persisted from current server evidence; only materialization may create `created_from_component`.
3. Independent successful mutations can overwrite reconciliation drafts calculated from the same stale aggregate. Every reconciliation-affecting command needs transactional revision/fingerprint protection and deterministic bounded retry or in-transaction recalculation.
4. Superseded source-created Transactions and statement-closing snapshots can remain eligible for current ledger/balance projections. Raven needs one explicit current-authority rule that preserves all history while excluding superseded authority.
5. Ordinary candidates are too broad. Only provisional manual/generated observations belong in ordinary matching; replay and legacy/source-backed compatibility require separate explicit paths.
6. Cross-period matching can reconcile one period while Account-month reads count the movement in another. The closeout must preserve the manual observation date and define one authoritative statement-backed financial date, or prohibit cross-period matching in v0.1. Grouped components must share one source row and one canonical financial date.
7. Source supersession does not yet bind all Account/Space/profile/context and source/period ownership checks inside the replacement transaction.
8. Superseded records remain physically present but are not fully traversable through semantic reads. Readable-history and active-mutation guards must be separate.
9. Attestation currently relies partly on count equality. It must prove exact component, component-claim, match, Transaction-claim, Transaction back-reference, source-claim, period-claim, and Account-context coherence.
10. Known final-authority repository outcomes can still collapse into generic `INTERNAL`; stable structured errors must cross every adapter.
11. The exact authorized ST-02 prompt must be preserved in `docs/prompts/raven-statement-truth-workline-st-02.md` by the main implementation workline.
12. Desktop and 390px QA remain pending if the user-managed Studio endpoint becomes available. The closeout must not start a replacement development server.
