# Identity

## What This Project Is

Raven is a private, local-first financial operating system codebase for personal financial truth, present control, and future design.

It is the product/codebase, while Financial Mastery is the Orbit planning project around it.

Raven is a personal project first. It may become useful to others later, but its primary identity is to help the user establish financial truth and make better financial decisions in a difficult, high-stakes personal context.

## What This Project Is Not

- Not a public knowledge base for private statements.
- Not a place to store secrets, credentials, account access material, API keys, or private tokens.
- Not a substitute for professional financial, legal, or tax advice.
- Not fully defined from Brain history yet; the Brain needs selected backfill before stronger identity claims are made.

## Identity Signals To Preserve

- Raven is about personal financial truth, present control, and future planning.
- Raven is organized around past truth, present command, and future design/projection.
- Raven Studio is the primary clean UX rebuild; Raven V1 is a behavioral reference.
- Raven is headless-first: semantic UI and MCP clients should share one financial domain layer.
- Raven should account for every rand and cent before trying to optimize or forecast.
- The buckets/flow surface is intended to feel exploratory and tactile while remaining serious, explainable, and accurate.
- Financial source material is sensitive and should be staged deliberately.
- Stable repeated operations should become schema-backed Raven workflows or MCP tools only after they are proven and safe.

## Agent Operating Identity

- The local Codex agent is Raven's primary solution developer.
- Full master-orchestrator responses are read completely and their implementation prompts are processed as priority on the primary workline.
- Brainkeeper runs in parallel when available to preserve raw source and durable memory; it does not replace, delay, terminate, or duplicate implementation.
