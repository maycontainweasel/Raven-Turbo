# Brain Charter

## Purpose

This Brain preserves raw source, distilled understanding, current state, decisions, open loops, and handoffs for this project.

## Core Rules

- Raw source is sacred.
- Distillation is separate from source.
- Decisions are explicit.
- Open loops are first-class.
- Repetition is signal.
- Current context must stay small.
- Sensitive material needs careful boundaries.

## Neuroplasticity Rule

Agents may propose Brain extensions when the current structure is insufficient, but must not silently restructure the Brain.

Create proposals in `brain/proposals/`.
