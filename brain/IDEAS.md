# Ideas

## IDEA-0001 - Buckets Lab As Present/Future Bridge

Source: RAVEN-INGEST-0001

Use a buckets/flow planning surface as the bridge between Raven's present-control layer and future-projection layer. The user should be able to model incoming money, allocations, expenses, savings containers, gates, and projections in one interactive environment.

## IDEA-0002 - Versioned Bucket Structures

Source: RAVEN-INGEST-0001

Preserve historical versions of bucket structures so Raven can show how allocation strategy changed over time without losing the meaning of older plans.

## IDEA-0003 - Explainability Ledger For Planning Rules

Source: RAVEN-INGEST-0001

Every allocation, gate, overflow, target contribution, and shortage adjustment should produce an explainable trail that can be reviewed in the UI.
